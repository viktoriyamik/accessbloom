# Accessibility statement for AccessBloom

AccessBloom is a portfolio project designed to support, not replace, a professional accessibility assessment. The application includes semantic headings, labeled form inputs, visible focus outlines, tabular report data, explicit action states, and keyboard-operated issue details. Automated tests alone cannot prove that our own interface meets WCAG 2.2 AA. Human evaluation with screen readers, keyboard-only navigation, zoom, high-contrast modes, and assistive technologies is planned.

If you encounter an accessibility barrier, open an issue in the public GitHub repository with the affected page, steps to reproduce, browser, and assistive technology (if comfortable sharing). Do not include personal or sensitive information in reports.
